# Word Burst

Merge Shooter for English vocabulary (A2–B1). Aim by dragging, release to shoot. Bubbles that mean the same thing (English synonyms, the Hungarian meaning, sometimes a picture) merge on contact; when every form of a meaning is collected the bubble bursts and its shockwave can set off chain reactions. Don't let the pile cross the red line.

Open `index.html` in a browser — no build step. Vocabulary lives in the `VOCAB` table at the top of the script.

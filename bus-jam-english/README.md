# Bus Jam English

Bus Jam style puzzle for English vocabulary (A1–A2). Passengers carry English words; free them in the right order and send each one to the bus of its category (FRUITS, ANIMALS, …). Wrong-bus passengers wait at the stop, which has only a few spots. 5 levels, each checked solvable by an exhaustive solver.

Open `index.html` in a browser — no build step. Levels live in the `LEVELS` table in the script.
